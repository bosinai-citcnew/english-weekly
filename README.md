# 每週英文教室

免費的英文學習網站，手機、電腦都能用，不用註冊。

👉 **開始使用：https://bosinai-citcnew.github.io/english-weekly/**

## 可以做什麼

- **讀文章**：每週 4 篇短文，點單字就能看中文和發音，也能整篇朗讀
- **背單字**：把生字收進單字本，用字卡或配對遊戲複習
- **練會話**：點餐、問路、看醫生等情境，分初級、中級、高級
- **週測驗**：聽、說、讀、寫四關

每週一會自動換一批新文章。

## 小提醒

- 學習進度存在自己的手機或電腦上，換裝置不會跟著過去。
- 語音辨識建議用 Chrome。
- 想要 AI 自由對話，可以在「會話」頁用自己的 Google 帳號免費開啟（選用）。
